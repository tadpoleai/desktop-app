# 优化阶段 1：深度图稳健显示与诊断

> 状态：已完成，等待 2–3 组真实数据验收。通过前不进入阶段 2。

## 本阶段改动

- 深度颜色从原始 min/max 线性映射改为 P2–P98 稳健映射；真实 xyz 和距离不变。
- 俯仰显示范围从原始 min/max 改为 P1–P99，并保留 5% 边缘余量。
- 过滤非有限点、0.3m 以下近点和 200m 以上远点。
- UI 显示实际数据源、栅格占用率、P2/P50/P98、过滤点数和俯仰范围。
- “单帧原始”改名为“原始时间窗”，避免误解 0.8 秒累积窗为设备单帧。
- GLIM 时间窗子图失败时仍允许退回整图，但页面显示黄色警告和失败原因，不再静默降级。

## 建议测试数据

至少选择以下 2–3 类：

1. 静止室内：墙面、门框、桌椅等深度层次清楚；
2. 静止室外或长距离场景：包含近物和 30m 以上目标；
3. 运动场景：同时比较 GLIM 重建与原始时间窗，并拖动时间轴。

## 每组数据记录

请截图或记下：

- 数据源标签：`GLIM 时间窗子图`、`GLIM 整图（降级）` 或 `原始时间窗`；
- 占用率；
- P2/P50/P98；
- 过滤点数；
- 俯仰范围；
- 原始时间窗的窗口秒数；
- 主观观察：结构是否更容易分辨、是否仍有明显空洞、重影、墙面增厚或颜色层次不足。

## 阶段判断

- 若颜色层次明显改善，但空洞/重影仍突出：阶段 1 通过，进入阶段 2，后续在阶段 4 处理运动补偿。
- 若 P2/P98 明显不合理或主体仍挤在单一颜色：留在阶段 1，调整分位数或增加手动深度范围。
- 若经常出现 `GLIM 整图（降级）`：记录黄色提示的具体原因；阶段 2 先修数据契约/产物稳定性。
- 若占用率很低：分别尝试原始时间窗 0.2、0.5、0.8、1.0 秒，记录覆盖率与拖影变化，不在本阶段盲目补洞。
- 若过滤点数异常高：检查量纲、坐标解码和设备自身点；暂不进入下一阶段。
